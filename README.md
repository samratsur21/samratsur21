## Hi there 👋

I'm Samrat

I work in information security, mostly on the governance side. Eleven years in,
split across GRC, IT audit, ISMS, privacy, third-party risk and cloud security
governance. These days I sit inside the CISO function of a European bank, which
means a lot of DORA, a lot of evidence, and a lot of translating control language
into things engineers will actually act on.

### Things I've worked on

- **Log4j remediation across 500+ systems.** Ran the tracking, prioritisation and
  closure end-to-end during the scramble. Still the clearest lesson I've had in how
  much asset inventory matters when the clock is running.
- **ISO 27001 ISMS programmes** — building them, running them, and auditing them.
  I'm a CQI/IRCA certified Lead Auditor, so I've seen both sides of the table.
- **ITGC and application control audits** across access management, change and
  operations.
- **Third-party risk at scale** using ServiceNow GRC — assessments, remediation
  tracking, and the reporting that goes with it.
- **Azure security governance** against CIS Benchmarks, with Defender for Endpoint
  and Qualys covering the vulnerability side.
- **Privacy work** under GDPR and ISO 27701.
- **KPI and KRI reporting for leadership.** Turning control data into something a
  non-security executive can decide is harder than it sounds, and I've
  spent real time getting better at it.

### What I'm into right now

AI governance — NIST AI RMF, ISO 42001 and the EU AI Act. I think the GRC side of
AI is going to look a lot like early cloud governance did, and I'd rather learn it
before it's urgent. Also reading up on API gateway security against the OWASP API
Security Top 10 and NIST SP 800-204. CISM is on the list for 2027.

### About this account

Most of my work isn't code, so this is mostly notes, scripts and reference material
I've found useful. If something here saves you an hour, that's the point.
